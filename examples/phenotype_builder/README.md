## 1. Overview

This directory provides reference scripts and synthesized OHDSI Circe JSON cohort definitions generated by the **TAXIS Automated Phenotype Recreation Engine**.

The engine compiles clinical intent structured as OHDSI Clinical Descriptions into standards-compliant Circe JSON cohort expressions, leveraging typed multi-domain edges from the **TAXIS Clinical Knowledge Graph** (112 relation codes).

---

## 2. Directory Contents

| File | Description | Key Features |
|---|---|---|
| **[`synthesize_circe_cohort.py`](./synthesize_circe_cohort.py)** | Reference Python synthesizer script | Translates clinical description dictionary and KG triples into standard OHDSI Circe JSON schemas. |
| **[`t2dm_recreated_circe.json`](./t2dm_recreated_circe.json)** | Synthesized Type 2 Diabetes Mellitus cohort | Primary condition (SNOMED `201826`), confirmatory HbA1c ($\ge 6.5\%$), first-line Metformin (`1503297`), and T1DM/gestational exclusions. |
| **[`ckd_recreated_circe.json`](./ckd_recreated_circe.json)** | Synthesized Chronic Kidney Disease Stage 3+ cohort | Primary condition (CKD Stage 3+), confirmatory eGFR ($< 60\text{ mL/min}/1.73\text{m}^2$), and acute kidney injury rule-out. |

---

## 3. Running the Synthesis Pipeline

To re-generate the Circe cohort definitions:
```bash
python examples/phenotype_builder/synthesize_circe_cohort.py
```

The resulting Circe JSON expressions can be directly imported into OHDSI Atlas, CIRCE compilers, or HADES evaluation pipelines (`CohortGenerator`, `CohortDiagnostics`, and `PheValuator`).
